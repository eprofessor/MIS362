MIS362 — Hermes Desktop Quick Guide

Use Hermes Agent Desktop on Windows 11. Use File Explorer to organize files, Notepad to edit text files, and OneNote to collect evidence.

First time

  1. Install Hermes Desktop from the official site.
  2. Choose OpenRouter as provider and an available free model. Enter any required API key only in provider settings; never share it in chat, screenshots or files. No payment details are needed for this assignment.
  3. From the Profiles selector or roster + control, choose New profile. Name it MIS362 and select it.
  4. Open File Explorer → Documents and create MIS362_Hermes_Workspace.

Every assignment

  1. Extract the assignment starter ZIP; put the GenAI folder into the workspace.
  2. Open .txt or .csv files in Notepad; use File → Save As → All files to keep the requested extension.
  3. Confirm the MIS362 profile and your OpenRouter free model, and start a new chat.
  4. Ask Hermes to draft, compare every factual answer with the provided files, and record actual outcomes.
  5. Put results in Documents\MIS362_Hermes_Workspace\GenAI##\output, replacing ## with the assignment number (02–09). Copy the report into OneNote, add evidence, export a PDF for D2L, and submit your reflection on the published assignment webpage.

Optional terminal policy

No terminal is required for these assignments. If your instructor specifically requests a terminal check, open PowerShell 7 (pwsh) from Start. Type $PSVersionTable.PSVersion and confirm major version 7 or later. If it is not available, ask instructor/ITS; do not substitute Windows PowerShell 5.1, Command Prompt, or Linux.

If something does not work

Record what happened. If Hermes cannot read a local file, paste only the fictional course text into chat and label that as a pasted-text test. If the local file write fails, use Notepad and label it manual. Your profile is not a security sandbox. Never share API keys or unrelated files.
