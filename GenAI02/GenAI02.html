Assignment Overview

Purpose: Install Hermes Desktop, create the MIS362 profile, and verify that the assistant can read a course file and prepare a draft.

Software: Hermes Agent Desktop for Windows 11, File Explorer, Notepad, and OneNote. These assignments use the MIS362 Hermes profile. No coding or terminal commands are required. If your instructor separately requests a terminal check, use PowerShell 7 (pwsh).

Save your work: Documents\MIS362_Hermes_Workspace\GenAI02. Do not upload credentials or personal data to an AI chat.

Learning Objectives

Install, locate, and verify the course profile, editor, and model/tool workflow.

Before You Begin

You need a Windows 11 laptop, Internet access, File Explorer, Notepad, and the instructor-provided instructions for your AI model/account. Use fictional course information only. If your laptop blocks the app installation, ask your instructor or ITS for help; do not bypass campus security settings.

Locate Your Working Folder and Archive

Assignment folder: Documents\MIS362_Hermes_Workspace\GenAI02. Save all completed work in Documents\MIS362_Hermes_Workspace\GenAI02\output, unless a step gives a different file location.

  1. Open File Explorer and choose Documents. Create a folder named MIS362_Hermes_Workspace.
  2. Download GenAI02_Starter_Files.zip, select Extract All, and copy the resulting GenAI02 folder into Documents\MIS362_Hermes_Workspace. Create an output folder inside GenAI02.
Install Hermes Desktop and prepare Notepad (Windows)
  1. Visit the official Hermes Desktop download page. Download and install the Windows application using the onscreen prompts. Launch Hermes Desktop from the Windows Start menu.
  2. Open Settings in Hermes Desktop and select OpenRouter as the AI provider. Use the course-provided API key or your approved free account configuration, entering any key only in the provider settings (never in chat, files, or screenshots). Choose an available OpenRouter free model; free-model availability can change. Do not add a payment method for this assignment. If no suitable free model appears, contact the instructor.
  3. Create your course profile: In Hermes Desktop, open the profile selector or profile rail. Choose New profile (or the + in the agent/profile roster), enter the exact name MIS362, and create it. Choose a blank/new profile rather than cloning an unrelated personal assistant. If a profile named MIS362 already exists, select it instead of making a duplicate.
  4. Select the MIS362 profile. Check that it uses the OpenRouter provider and a free model; settings may need to be configured separately for this profile. Start a new chat in MIS362.
  5. In Notepad, open Documents\MIS362_Hermes_Workspace\GenAI02\GenAI02_Hermes_Setup_Verification_Template.txt. Save a working copy in Documents\MIS362_Hermes_Workspace\GenAI02\output\GenAI02_Setup_Verification.txt using File → Save As. In the Save As dialog choose All files so the filename remains .txt.
Verify the Installation and Capture Evidence
  1. In File Explorer, locate Documents\MIS362_Hermes_Workspace\GenAI02\Setup_Input.txt and read it with Notepad. Record the expected content in your verification report.
  2. In your MIS362 chat, ask: “Please read only the file Documents\MIS362_Hermes_Workspace\GenAI02\Setup_Input.txt in my Documents\MIS362_Hermes_Workspace folder. Show the contents and the actual file-tool result. Do not change any files.” If the agent cannot read it, use an explicit full path in a follow-up. If tools remain unavailable, record NOT RUN; do not pretend the read occurred.
  3. Compare Hermes’s answer to the open Notepad file. Record PASS or NEEDS CORRECTION and whether it was an actual file read or text pasted into chat.
  4. Ask Hermes to draft two lines for Documents\MIS362_Hermes_Workspace\GenAI02\output\Setup_Output.txt: Course: MIS362 and Profile: MIS362. Review the proposed text. You may save it yourself with Notepad, or approve Hermes to write only this file. Record which method was actually used.
  5. Open Documents\MIS362_Hermes_Workspace\GenAI02\Setup_Output.txt in Notepad and verify the two lines. Close and reopen Hermes Desktop; select MIS362 again. Record the selected profile, model, file check, and any problems in your report.
Security Boundaries and Stop Conditions

Your MIS362 profile organizes course sessions; it is not a secure filesystem boundary. Use only the assigned fictional files. Ask for a draft before allowing changes. Do not permit Hermes to access other folders, send email, change business records, or expose your API key. If a tool is unavailable, record the actual limitation and use a manual Notepad check.
