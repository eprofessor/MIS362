Learning Objectives

In this assignment, you will examine how data types, sorting, and encoding affect SmartBean's databases and trusted information.

After completing this assignment, you will be able to:

  1. Distinguish numeric data from text data.
  2. Explain why numbers and text may sort differently.
  3. Identify business values that should remain text even when they contain only digits.
  4. Explain how character encoding represents text for computer storage and exchange.
  5. Evaluate how incorrect data types or encoding can reduce trust in database results.

Assignment Overview

SmartBean stores quantities, prices, product IDs, ZIP codes, employee IDs, customer information, and product names. These values may look similar on a screen but require different data types and may sort, calculate, or match differently.

Correct data types and encoding help databases return accurate searches, joins, reports, and decisions. Incorrect choices can remove leading zeros, prevent arithmetic, produce unexpected sorting, or corrupt imported text.
