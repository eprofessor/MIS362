The shared MIS362_Student_Quick_Guide.html is linked from every assignment.

Publish each GenAI##.html file using your existing course website process.
Keep the relative GenAI##_Starter_Files.zip file in the same folder as its HTML page.
Keep MIS362_Student_Quick_Guide.html one directory above the assignment folders,
so the relative link ../MIS362_Student_Quick_Guide.html continues to work.

reflection textarea, and normal published-page submission workflow.
