Learning Objectives

In this assignment, you will use Excel and a browser demonstration to examine customer convenience, mobile checkout, web-service data, and privacy controls.

After completing this assignment, you will be able to:

  1. Compare e-commerce and mobile-commerce channels from the customer's perspective.
  2. Interpret a mobile checkout funnel and identify an important point of customer loss.
  3. Explain how structured web-service data supports a website or mobile application.
  4. Evaluate how location permissions and data-minimization choices affect customer privacy.
  5. Recommend controls that make mobile ordering reliable and trustworthy.

Assignment Overview

SmartBean serves customers through three channels: in-store purchase, mobile pickup, and SmartBean delivery. Each channel offers different forms of convenience and depends on accurate data, reliable services, and customer trust.

Exercise 4 — Web-Service Data and Trust

Inspect this sample response from a SmartBean service: 

{
  "storeId": "SB-MAIN",
  "item": "Mocha",
  "available": true,
  "price": 5.25,
  "pickupMinutes": 12,
  "mobileOrdering": true
}
  1. Open 3-ServiceData.
  2. Review how the mobile application uses each JSON field.
  3. Consider what the application should do if a field is missing, invalid, or unavailable.
  4. Open 4-PrivacyControls and review payment, confirmation, service-failure, and customer-data controls.
  5. Focus on how web services improve convenience while controls preserve trust.
